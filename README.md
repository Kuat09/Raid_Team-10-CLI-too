# Raid_Team-10-CLI-too

Kanban CLI project

Это интерактивное CLI-приложение для управления задачами в стиле Kanban, написанное на языке Go.

Программа позволяет создавать, просматривать, выполнять и удалять задачи. Задачи сохраняются в файл `tasks.txt` и остаются доступными после перезапуска программы.

## Требования

Убедитесь, что у вас установлен Go версии 1.18 или выше.

## Как запустить

1) Clone the repository:
```bash
https://github.com/Kuat09/Raid_Team-10-CLI-too.git
```
*(use HTTPS link)*
2) Перейдите в папку проекта:
```bash
cd Raid_Team-10-CLI-too
```
3) Запустите программу:
```bash
go run main.go
```
4) Для просмотра подсказки:
```bash
go run main.go --help
```

Что может делать программа:

Создавать новые задачи.
Помечать задачи как выполненные.
Удалять задачи.
Просматривать все задачи в виде ASCII-таблицы.
Сохранять задачи в tasks.txt.
Загружать задачи из tasks.txt при запуске программы.
Показывать подсказку с помощью --help.

В программе используются два статуса:

TODO — задача ещё не выполнена.
DONE — задача выполнена.

Интерактивное меню содержит пять действий:

1. Создать таску
2. Пометить выполненным
3. Удалить таску
4. Все таски
5. Завершить работу программы

1. Создать таску

Создаёт новую задачу со статусом TODO.

2. Пометить выполненным

Позволяет указать ID задачи и изменить её статус с TODO на DONE.

3. Удалить таску

Удаляет задачу по её ID.

4. Все таски

Показывает все задачи в виде ASCII-таблицы.

5. Завершить работу программы

Завершает работу приложения.

Все задачи хранятся в файле tasks.txt.

Каждая задача записывается на отдельной строке в следующем формате:

id;status;title

Например:

1;DONE;Write tests
2;TODO;Fix bug
3;TODO;Deploy

Где:

id — уникальный номер задачи.
status — статус задачи: TODO или DONE.
title — название задачи.

Программа проверяет введённые пользователем данные:

Название задачи не может быть пустым.
Название задачи не может быть длиннее 20 символов.
ID задачи не может быть пустым.
ID задачи должен быть числом.
Максимальное количество задач — 99.

Задачи отображаются в виде ASCII-таблицы.

Пример:

+----+----------------------+-------------+
| ID | Title                | Status      |
+----+----------------------+-------------+
|  1 | Write tests          | DONE        |
|  2 | Fix bug              | TODO        |
|  3 | Deploy               | TODO        |
+----+----------------------+-------------+
Пример работы

Запускаем программу:

go run main.go

Пример сессии:

=== МЕНЮ ЗАДАЧ ===
1. Создать таску
2. Пометить выполненным
3. Удалить таску
4. Все таски
5. Завершить работу программы
Выберите действие (1-5): 4

Программа показывает:

+----+----------------------+-------------+
| ID | Title                | Status      |
+----+----------------------+-------------+
|  1 | Write tests          | DONE        |
|  2 | Fix bug              | TODO        |
|  3 | Deploy               | TODO        |
+----+----------------------+-------------+

Если выбрать 2 и ввести ID 2, задача Fix bug изменит статус с TODO на DONE.

После этого доска будет выглядеть так:

+----+----------------------+-------------+
| ID | Title                | Status      |
+----+----------------------+-------------+
|  1 | Write tests          | DONE        |
|  2 | Fix bug              | DONE        |
|  3 | Deploy               | TODO        |
+----+----------------------+-------------+
Подсказка

go run main.go --help

Команда показывает информацию о запуске программы и доступных действиях меню.
